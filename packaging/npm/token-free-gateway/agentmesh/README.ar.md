# تكامل MuhanAI × OpsMaxx — العربية (Arabic)

> هذه هي الترجمة العربية لـ [README.md](../README.md). النسخة الإنجليزية الأصلية هي دائماً الأحدث.

## ما الذي تحصل عليه

يمكن لشبكة عملاء MuhanAI الآن تشغيل **بنية تحتية حقيقية** نيابة عنك — و**مفاتيح API الخاصة بك لا تغادر جهازك أبداً**.

| القدرة         | ما يمكن للعميل فعله                       | ما يبقى على جهازك                   |
| -------------- | ----------------------------------------- | ----------------------------------- |
| SSH            | فتح الجلسات، تنفيذ الأوامر، تتبع السجلات  | كل أمر يتطلب موافقتك                |
| SFTP           | قراءة وكتابة الملفات                      | الكتابة تتطلب موافقتك               |
| قواعد البيانات | تنفيذ استعلامات SELECT، تطبيق الكتابات    | الكتابات تتطلب موافقة _مزدوجة_      |
| الأنفاق        | فتح SOCKS5 / WireGuard / OpenVPN          | كل فتح يتطلب موافقتك                |
| الخزنة         | قراءة البيانات الوصفية، تخزين أسرار جديدة | الأسرار لا تغادر مضيف OpsMaxx أبداً |

## كيف تتكامل

```
┌──────────────────┐
│  MuhanAI Web UI  │  ← يرى المستخدم المطالبات ويوافق على الكتابات
│  (muhanai.com)   │
└────────┬─────────┘
         │ متوافق مع OpenAI + MCP
         ▼
┌──────────────────┐  عقد OpsMaxxBridge      ┌──────────────────┐
│  agent-gateway   │  ←——————————————————→  │  OpsMaxx سطح     │
│  + agent-daemon  │     stdio / IPC          │  المكتب (Electron)│
│  + mcp-routes    │                          │  • SSH/SFTP/DB    │
│  + opsmaxx-bridge│                          │  • safeStorage    │
└────────┬─────────┘                          │  • بطاقة الموافقة │
         │                                    └──────────────────┘
         │ peer-mesh (libp2p)
         ▼
  عملاء آخرون / أجهزة أخرى / قوائم bot.muhanai.com
```

## نموذج التهديد في فقرة واحدة

أخطر وضع فشل في "عميل المتصفح" هو أن يقوم النموذج بتنفيذ `DROP TABLE users;` دون علم المستخدم. يتعامل التكامل مع كل إجراء على أنه ينتمي إلى إحدى فئات المخاطر الثلاث (`safe` / `needs-approval` / `high-risk-needs-double-approval`)، المُعلنة مرة واحدة في خريطة `RISK` في `packages/opsmaxx-bridge/src/types.ts`. تستعلم طبقة MCP في `mcp-routes.ts` عن فئة كل أداة وتوجهها عبر الحارس البشري الموجود قبل إعادة التوجيه إلى OpsMaxx. يسجل سجل التدقيق كل استدعاء بحيث يمكن إعادة بناء قرار النموذج لاحقاً.

## بداية سريعة (مطور)

```bash
# 1. تثبيت OpsMaxx (مجاني، MIT، بدون حساب)
#    https://github.com/OpsMaxx/OpsMaxx
#
# 2. أضف إدخالات SSH/DB/الخزنة التي سيستخدمها العميل
#    يظهر كل إدخال في لوحة تحكم MuhanAI كـ"Trusted peer"
#
# 3. تشغيل agent-daemon الخاص بـ MuhanAI محلياً
cd packaging/npm/token-free-gateway/agentmesh
pnpm install
pnpm --filter @agentmesh/opsmaxx-bridge typecheck
pnpm --filter @agentmesh/opsmaxx-bridge test
```

## بداية سريعة (مستخدم نهائي)

1. ثبّت [OpsMaxx](https://github.com/OpsMaxx/OpsMaxx).
2. سجّل الدخول إلى [muhanai.com](https://muhanai.com) وافتح صفحة _Trusted peers_ (P2P → OpsMaxx).
3. اقرن نسخة OpsMaxx المحلية بالنقر على "Approve" في بطاقة الموافقة التي تظهر في OpsMaxx.
4. اطلب من العميل أي شيء يحتاج بنية تحتية حقيقية. راقب بطاقات الموافقة.
