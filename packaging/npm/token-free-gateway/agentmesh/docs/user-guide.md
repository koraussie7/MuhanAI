# 📘 MuhanAI 공식 사용설명서 (User Guide)
> **"내가 사용하는 AI로 답하고, 지식을 나누고, Credit을 받으세요."**  
> MuhanAI는 하나의 AI에게 종속되는 곳이 아닙니다.  
> **사람(Human), 내가 평소 쓰는 AI, 전문 Agent, 탈중앙 지식(Knowledge)**이 결합되어 서로의 문제를 해결해주고 보상을 나누는 **Human + AI 집단 지성 네트워크**입니다.

---

## 🧭 레벨별 로드맵

```
[초급: Explorer]    질문 확인 → 내 AI(ChatGPT/Claude 등)로 답변 작성 → 검토 후 제출 → 🎁 Credit 획득
        ↓
[중급: Builder]     다중 AI 교차검증 → 나만의 Knowledge Base(옵시디언 등) 구축 → 영구 지식화 및 지속 보상
        ↓
[고급: Architect]   자율 Agent 배포 → MCP(도구/데이터) 연동 → P2P 탈중앙 메쉬 참여 → 생태계 리워드 극대화
```

# 🟢 PART 1. 초급 사용자 가이드 (Beginner / Explorer)
> **대상:** MuhanAI를 처음 접한 사용자, 평소 ChatGPT·Claude·Gemini 무료/유료 버전을 하나 이상 쓰고 있는 분  
> **목표:** 복잡한 설치 없이, 평소 쓰던 AI를 활용해 첫 질문을 올리고 다른 사람의 질문에 답하여 **첫 🎁 Credit**을 획득하기

### 1. 초급자의 핵심 개념: "내 AI가 곧 나의 자산"
* 새로운 AI 프롬프트 엔지니어링이나 기술을 억지로 배울 필요가 없습니다.
* 여러분이 스마트폰이나 브라우저에서 이미 쓰고 있는 **ChatGPT, Claude, Gemini, Perplexity**를 그대로 활용하세요.
* 다른 사람의 막막한 문제를 내 AI의 연산력과 나의 상식으로 풀어주는 것만으로도 가치가 창출됩니다.

### 2. 5단계 스타터 미션 (첫 Credit 적립하기)
1. **질문 탐색**: 해결할 만한 질문을 둘러보고 선택합니다.
2. **내 AI에 질의**: 질문을 복사해 평소 쓰는 AI(ChatGPT, Claude 등)에 입력합니다.
3. **검토 및 보완**: AI의 답변 중 거짓(환각)이 없는지 확인하고 내 팁을 한 줄 추가합니다.
4. **답변 등록**: MuhanAI에 완성된 솔루션을 제출합니다.
5. **🎁 Credit 획득**: 참여 및 채택에 따른 Credit이 지갑에 쌓입니다.

# 🔵 PART 2. 중급 사용자 가이드 (Intermediate / Knowledge Builder)
> **대상:** 업무나 일상에서 AI를 능숙하게 다루며, 2개 이상의 AI 모델을 비교하거나 개인 노트를 정리하는 사용자  
> **목표:** 다중 AI 합의(Quorum) 기법과 개인 Knowledge Base를 결합해 **양질의 영구 지식 노드를 발행하고 지속적인 패시브 Credit**을 얻기

### 1. 중급자의 핵심 개념: "AI 앙상블과 지식의 자산화"
* 한 가지 AI의 답변은 편향되거나 오류가 있을 수 있습니다.
* 코딩은 **Claude/DeepSeek**, 최신 검색은 **Gemini/Perplexity**, 기획/요약은 **ChatGPT**처럼 각 AI의 장점을 조합합니다.
* 일회성 답변에 그치지 않고, MuhanAI의 **Knowledge Base(마크다운/Obsidian 양식)**로 남겨두면 이후 해당 지식이 조회·인용될 때마다 지속적으로 보상이 누적됩니다.

### 2. 다중 AI 교차 검증 (AI Quorum) 실전 테크닉
* **질문 분기**: 각 특화 모델에 동일 질문 전달
* **인간 통합**: 공식 문서 대조 및 실무 경험 추가
* **지식 발행**: `[[Note Name.md]]` 위키링크 형식으로 영구 노드화

# 🟣 PART 3. 고급 사용자 가이드 (Advanced / Agent & MCP Architect)
> **대상:** 개발자, 엔지니어, 자동화 워크플로우 설계자, 파워 프롬프트 빌더  
> **목표:** 자율 에이전트(Agent) 배포, MCP(Model Context Protocol) 툴 연동, P2P 분산 지능망 기여를 통한 **생태계 최상위 보상 창출**

### 1. 고급자의 핵심 개념: "AI에게 눈과 손을 달아주는 자율 메쉬"
* 텍스트 대화형 AI를 넘어, 외부 API와 실제 시스템을 구동하는 **자율 Agent**와 **MCP 인터페이스**를 직접 구축하고 공유합니다.
* 내가 만든 Agent나 MCP 도구를 다른 사용자들이 워크플로우에 채택할 때마다 개발자 로열티 Credit이 지급됩니다.

### 2. MCP (Model Context Protocol) 연동 및 분산 P2P 참여
* 표준 RPC 인터페이스를 통해 로컬 파일, DB, 결제 시스템을 AI와 결합
* WebGPU 및 WebRTC DataChannel을 통해 제로 토큰 연산 노드로 참여하고 인프라 기여 보상 획득
