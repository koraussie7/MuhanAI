브라우저에서 직접 동작하는 P2P 에이전트 메시시, 분산 지식 그래프, 그리고
MCP(Model Context Protocol) 도구를 다루는 기술 블로그입니다.

MuhanAI는 중앙 서버 없이 peer-to-peer로 동작하는 에이전트 네트워크를 지향합니다.
libp2p 기반 전송, WebRTC 피어 연결, 브라우저 SSE 브리지, 그리고 평판 기반 크레딧
시스템을 함께 구성합니다.
